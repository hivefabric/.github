# Hive SDK (`hive-sdk`)

## Role

Shared contract and identity/runtime package source for the platform.

## Packages

- `hive-sdk`: protocol/domain contracts
- `hive-iam`: authn/authz primitives
- `hive-node`: reusable node orchestration SDK

## Why it matters

This repository is the contract backbone that reduces drift between control-plane and runtime implementations.
